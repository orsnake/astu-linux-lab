# System Information

## Update package lists
```bash
sudo apt update
```

Updates package lists from repositories on Debian/Ubuntu systems.

---

## Show current user
```bash id="1h4frc"
whoami
```

Displays the currently logged-in user.

---

## Show IP addresses
```bash id="o5m77s"
ip a
```

Displays network interfaces and IP addresses.

---

## Check listening ports
```bash id="pkp5te"
ss -tulnp
```

Displays listening services and open ports.

---

## Check disk usage
```bash id="8g5vv0"
df -h
```

Displays disk usage in human-readable format.
